   107→   107→1. Telemetry
   108→   108→
   109→   109→Stops Windows from sending diagnostic data, application usage statistics and crash reports to Microsoft.
   110→   110→
   111→   111→
   112→   112→
   113→   113→
   114→   114→
   115→   115→What it does
   116→   116→
   117→   117→Sets AllowTelemetry=0 in both the policy and legacy data-collection paths, disables the DiagTrack and dmwappushservice services that ship telemetry, turns off CEIP (Customer Experience Improvement Program), the Inventory Collector and the Application Impact Telemetry agent, and disables every scheduled task under \Microsoft\Windows\Application Experience\, \Customer Experience Improvement Program\ and \Feedback\Siuf\.
   118→   118→
   119→   119→
   120→   120→
   121→   121→Can it be undone?
   122→   122→
   123→   123→Reversible. Re-enable the services with sc config <name> start= auto and re-enable the scheduled tasks with schtasks /Change /Enable, or roll back via System Restore.
   124→   124→
   125→   125→
   126→   126→
   127→   127→
   128→   128→cmd (administrator) — copy & paste
   129→   129→

   132→   132→:: Disable Windows telemetry, diagnostic data and CEIP

   134→   134→reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\DataCollection" /v AllowTelemetry /t REG_DWORD /d 0 /f
   135→   135→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v DoNotShowFeedbackNotifications /t REG_DWORD /d 1 /f
   136→   136→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v LimitDiagnosticLogCollection /t REG_DWORD /d 1 /f
   137→   137→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection" /v LimitDumpCollection /t REG_DWORD /d 1 /f
   138→   138→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AppCompat" /v AITEnable /t REG_DWORD /d 0 /f
   139→   139→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AppCompat" /v DisableInventory /t REG_DWORD /d 1 /f
   140→   140→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AppCompat" /v DisableUAR /t REG_DWORD /d 1 /f

   182→   182→2. AI features
   183→   183→
   184→   184→Removes Windows Copilot, Recall, Click-to-Do and the generative AI tools baked into Paint and Photos.
   185→   185→
   186→   186→
   187→   187→
   188→   188→
   189→   189→
   190→   190→What it does
   191→   191→
   192→   192→Sets DisableAIDataAnalysis=1 and AllowRecallEnablement=0 to fully block Recall (Win 11 24H2+), and tries to remove Recall as an optional Windows feature. Also enforces TurnOffWindowsCopilot=1 in both HKLM and HKCU, hides the Copilot button in the taskbar, removes the Copilot AppX package and disables Click-to-Do, Image Creator, Cocreator and Generative Fill in Paint.
   193→   193→
   194→   194→
   195→   195→
   196→   196→Can it be undone?
   197→   197→
   198→   198→Reversible at the policy level (delete the values under HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsAI). The Copilot AppX package can be reinstalled from the Microsoft Store. Recall, once removed as an optional feature, requires re-enabling via Settings > Optional features.

   247→   247→3. Cortana / Bing
   248→   248→
   249→   249→Removes Cortana and prevents the Start menu from sending your search queries to Bing.
   250→   250→
   251→   251→
   252→   252→
   253→   253→
   254→   254→
   255→   255→What it does
   256→   256→
   257→   257→Sets AllowCortana=0 and DisableWebSearch=1 under the Windows Search policy, turns off ConnectedSearchUseWeb, AllowCloudSearch and BingSearchEnabled, and removes the Cortana AppX package for all users along with its provisioned package so it does not come back for new users.
   258→   258→
   259→   259→
   260→   260→
   261→   261→Can it be undone?
   262→   262→
   263→   263→Reversible. Reinstall Cortana from the Microsoft Store and delete the policy keys to restore Bing search in the Start menu.
   264→   264→
   265→   265→
   266→   266→
   267→   267→
   268→   268→cmd (administrator) — copy & paste
   269→   269→
   270→   270→

   272→   272→:: Disable Cortana, Bing web search and cloud search in the Start menu
   273→   273→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v AllowCortana /t REG_DWORD /d 0 /f
   274→   274→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v DisableWebSearch /t REG_DWORD /d 1 /f
   275→   275→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v ConnectedSearchUseWeb /t REG_DWORD /d 0 /f
   276→   276→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v AllowSearchToUseLocation /t REG_DWORD /d 0 /f
   277→   277→reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\Windows Search" /v AllowCloudSearch /t REG_DWORD /d 0 /f
   278→   278→reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Search" /v BingSearchEnabled /t REG_DWORD /d 0 /f
   279→   279→reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Search" /v CortanaConsent /t REG_DWORD /d 0 /f

   297→   297→
   298→   298→Hardens advertising, location, activity, clipboard and personalization settings.
   299→   299→
   300→   300→
   301→   301→
   302→   302→
   303→   303→
   304→   304→What it does
   305→   305→
   306→   306→Disables the per-user Advertising ID, Activity History / Timeline (EnableActivityFeed=0, PublishUserActivities=0, UploadUserActivities=0), location tracking via lfsvc and the location consent store, cloud clipboard sync (AllowCrossDeviceClipboard=0), speech/handwriting/typing data collection, lock-screen Spotlight ads and Start menu suggestions/Consumer Features.

   309→   309→
   310→   310→Can it be undone?

   408→   408→6. Firewall
   409→   409→
   410→   410→Adds outbound Windows Firewall rules that block ~20 known Microsoft telemetry endpoints.
   411→   411→
   412→   412→
   413→   413→
   414→   414→
   415→   415→
   416→   416→What it does
   417→   417→
   418→   418→Resolves each telemetry hostname (vortex.data.microsoft.com, watson.telemetry.microsoft.com, settings-win.data.microsoft.com, etc.) to its current IP addresses and creates an outbound block rule for those IPs. This works as a second layer of defense in case any process tries to bypass the policy-level telemetry switches.
   419→   419→
   420→   420→
   421→   421→
   422→   422→Can it be undone?
   423→   423→
   424→   424→Reversible. Open wf.msc, go to Outbound Rules and delete the rules whose name starts with 'Block telemetry:'.
   425→   425→
   426→   426→
   427→   427→
   428→   428→
   429→   429→cmd (administrator) — copy & paste
   430→   430→
   431→   431→
   432→   432→@echo off

   594→   594→ 4. Frequently asked questions about debloating Windows
   595→   595→
   596→   596→ Is it safe to debloat Windows 11? 
   597→   597→ 
   598→   598→Yes, when you stick to user-level changes such as the ones on this page. Every script disables features through documented registry policies, official Group Policy keys, the Windows Firewall and the standard Remove-AppxPackage command — nothing patches system files. You should still create a System Restore point before running anything (Start > type 'Create a restore point') so you can roll back in one click if you change your mind.
   599→   599→ Can I undo the changes made by these debloat scripts? 
   600→   600→ 
   601→   601→Yes. All telemetry, AI, Cortana, privacy and Edge changes are pure registry policies — delete the corresponding keys under HKLM\SOFTWARE\Policies\Microsoft to revert. Disabled services can be re-enabled with 'sc config <name> start= auto'. UWP apps removed by the bloatware script can be reinstalled from the Microsoft Store. The OneDrive uninstall is fully reversible by reinstalling OneDrive from the official Microsoft download page.
   602→   602→ Will debloating Windows break Windows Update or the Microsoft Store? 
   603→   603→ 
   604→   604→No. The scripts on this page intentionally do not touch Windows Update, the Microsoft Store, Defender or any core servicing component. Only telemetry, AI, advertising, Cortana/Bing, OneDrive and pre-installed UWP apps are affected, so your machine continues to receive security updates normally.
   605→   605→ How do I disable Windows Recall on Windows 11 24H2? 
   606→   606→ 
   607→   607→Set 'DisableAIDataAnalysis' to 1 and 'AllowRecallEnablement' to 0 under HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsAI (and the matching HKCU path), then run 'Disable-WindowsOptionalFeature -Online -FeatureName Recall -Remove' from an elevated PowerShell. The 'AI features' script in section 3 of this guide does both automatically.
   608→   608→ How do I remove Microsoft Copilot from Windows 11? 
   609→   609→ 
   610→   610→Apply the 'TurnOffWindowsCopilot=1' policy under HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot, hide the taskbar button by setting 'ShowCopilotButton=0' under HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced, then remove the AppX package with 'Get-AppxPackage -AllUsers *Copilot* | Remove-AppxPackage -AllUsers'. The 'AI features' script bundles all three steps.
   611→   611→ Do I need to run these debloat scripts as administrator? 
   612→   612→ 
   613→   613→Yes. Every script writes to HKLM, modifies Windows services, schedules tasks, removes provisioned AppX packages or creates Windows Firewall rules — all of which require an elevated Command Prompt or PowerShell. Section 2 of this page shows three different ways to open an administrator terminal on Windows 10 and Windows 11.
   614→   614→ Does this Windows debloat guide work on both Windows 10 and Windows 11? 
   615→   615→ 
   616→   616→Yes. Every policy, service and AppX package targeted by the scripts exists on both Windows 10 (1809 and later) and Windows 11 (including 23H2 and 24H2). AI-specific items such as Recall and Click-to-Do simply have nothing to disable on Windows 10 and the script silently skips them.
